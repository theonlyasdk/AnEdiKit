# Introduction to AnEdiKit
AnEdiKit is what you can call an "Engine" or a development platform for making GUIs for command line tools. It can also be used to make chained macro workflows i.e you process a file through multiple tools one after another. 

## Basic terminology
1. A "Kit" is a workflow aka a GUI for a command line tool. You can add parameters through the parameter block editor, then you can write a script which will be then executed when you run the Kit.
