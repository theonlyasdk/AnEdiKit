# Project Goals
Here are the things I'm hoping to accomplish with this project:

For the current version, which is the version built with vanilla HTML/CSS/JS, the main goals are:
1. Stability
2. Consistency
3. Performance
4. ~~Features~~ (Later)


There is a plan to rewrite this projet in React, and the goals for that version will be:
1. Stability
2. Consistency
3. Performance
4. Features (This time, for real)
6. Maintainability
7. Scalability

It will use a component-based architecture, which will make it easier to maintain and scale the project in the future. The React version will also allow for better state management and reusability of components, which will improve the overall development experience.

It will use shadcn/ui for the UI components, which will provide a consistent and modern look and feel across the application. This will also help with accessibility and responsiveness, ensuring that the application works well on different devices and screen sizes.
